# 多仓库与 GitLab 实施记录

## 已确认需求

- 飞书群分别配置可用 Git 仓库，一个群可绑定多个仓库。
- 智能体根据任务选择一个或多个已绑定仓库；无法确定时向发起人澄清。
- 未绑定群及未配置独立仓库列表的私聊不创建执行任务，提示先配置；不回退到全局 GitHub 仓库。
- 自建 GitLab 为完整来源：Issue、MR、评论、CI、名单和准入，以及 Git 操作、MR 创建和状态跟踪。
- 保留已有工单、配置与无关代码，不修改线上凭据。
